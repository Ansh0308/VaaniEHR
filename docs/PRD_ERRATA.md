# PRD_ERRATA.md - statements in PRD v1.0 contradicted by the ClinicOS audit

The PRD itself is **not edited**. "What is true" cites `CLINICOS_AUDIT.md` (A) or `CLINICOS_INTEGRATION_FACTS.md` (F, with question number) and the decisions in `DECISIONS.md` (D1-D11). Line numbers refer to the PRD file as read on 2026-10-14. Rule applied: code wins for ClinicOS facts, the PRD wins for VaaniEHR scope (D5).

> **Update 2026-10-14 (ADR-D15):** PRD v1.1 is now `DOCUMENTS/VaaniEHR_PRD.md`; v1.0 is `DOCUMENTS/archive/VaaniEHR_PRD_v1.0.md`. The "What it says" column and the line numbers below refer to **v1.0**. The last column records whether v1.1 fixes the row (checked against v1.1 text and its Appendix F). **Rows not yet covered: 28 (unknown-age behaviour of the safety rule) and 29 (adapter must drop ClinicOS private `notes`).** Both are proposed as v1.2 edits or Phase 2/12 design rules; the PRD itself is not edited by the assistant.
