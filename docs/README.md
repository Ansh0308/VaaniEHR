# Documentation index

One line for every document in `docs/`. `npm run check` fails if a file in `docs/` is not listed here (`scripts/check-docs-index.mjs`). Start with the project [README](../README.md), then [CONTEXT.md](CONTEXT.md). The requirements are in `DOCUMENTS/VaaniEHR_PRD.md` (PRD v1.1, the source of truth); `DOC_INDEX.md` below is a digest of that PRD, not a list of documents.
